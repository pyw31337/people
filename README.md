# 👤 렛츠피플 (Let's People) — 글로벌 12만 미디어 노출 인물 백과 & 30개년 노화·인맥 온톨로지

> **국내외 미디어에 노출되었던 이력이 있는 124,500명 인물 전수 원장**과 **328,000개 다국적 인맥(학연·지연·혼맥·투자) 링크, 30개년 노화(Aging) 타임랩스 사진 아카이브**를 결합한 온톨로지 기반 글로벌 휴먼 인텔리전스 마이크로서비스입니다.

---

## 📌 핵심 기능 및 서비스 범위
1. **국내외 미디어 노출 인물 6대 카테고리 전수 색인**:
   - 빅테크·AI·스타트업 창업가 (젠슨 황, 일론 머스크, 샘 알트만 등)
   - 국내외 정계·관료·외교 지도부
   - 글로벌 금융·헤지펀드·VC (워런 버핏, 피터 틸 등)
   - 언론인·팟캐스트·소셜미디어 빅마우스 (조 로건, 터커 칼슨 등)
   - 문화·예술·영화·엔터테인먼트 (봉준호, BTS 등)
   - 과학·노벨상·학술 석학 (데미스 하사비스, 제프리 힌튼 등)
2. **30개년 노화(Aging) 타임랩스 사진**:
   - 인물 사진 검증 직후 **WebP 84.7% 압축(평균 1.2MB ➔ 184KB)** 후 Cloudflare R2 / S3 즉시 오프로드
   - 180일 TTL 주기 체크로 중복 수집 배제 및 5·10·20년 단위 노화 변화만 추적
3. **글로벌 다차원 인맥 탐색기**:
   - 스탠퍼드·하버드·서울대 학맥, 페이팔 마피아 등 창업 동문, 재벌가 혼맥 온톨로지 링크.

## 🔗 온톨로지 연합 URN
- 인물 원장 URN: `urn:people:person:{nationality}:{entity_id}`
- 인맥 관계망 URN: `urn:people:network:{relation_type}:{person_a}:{person_b}`
