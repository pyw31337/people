# 👤 렛츠피플 (Let's People) — 글로벌 12만 인물 백과 & 영화·뮤지컬·K-POP 필모그래피 온톨로지

> **"모든 일은 사람이 한다"**는 대원칙 하에, **글로벌 124,500명 인물 원장**과 **영화·뮤지컬·K-POP 24,800명 필모그래피/스테이지그래피/디스코그래피**, **30개년 노화 사진 아카이브**를 결합하여 **컬처플로우(CultureFlow), 뉴스보드, 렛츠로, 렛츠에셋, 렛츠인슈 전반에 인물 데이터를 공급하는 단일 진실 공급원(SSOT)** 마이크로서비스입니다.

---

## 📌 핵심 기능 및 서비스 범위
1. **컬처플로우(CultureFlow) 연계 문화예술 필모그래피 원장**:
   - **영화배우/감독**: 영화·드라마 필모그래피(박스오피스 관객수, 아카데미/칸 영화제 수상, 감독-배우 페르소나 협업망)
   - **뮤지컬·연극 배우**: KOPIS 공연예술전산망 연동, 대표 무대 스테이지그래피(캐스팅 배역, 극장, 티켓파워)
   - **K-POP / 뮤지션**: 앨범 디스코그래피(음원차트 PAK, 작사/작곡 크레딧, 프로듀서 협업망)
2. **모든 서비스의 중심: 전방위 휴먼 인텔리전스 허브**:
   - 컬처플로우(공연인) ⇄ 뉴스보드(사건인물) ⇄ 렛츠로(법조인) ⇄ 렛츠에셋(기업인/임원) ⇄ 렛츠인슈(손사/자문의) 상호 연계
3. **30개년 노화(Aging) 타임랩스 사진**:
   - 데뷔 신인기 ➔ 성장기 ➔ 전성기 ➔ 현재까지 WebP 84.7% 압축(184KB) 및 Cloudflare R2 즉시 이관
4. **24/7 무인 자동 수집 크론**:
   - GitHub Actions 매일 05:00 KST 자동 실행으로 신규 캐스팅/인사이동 380~500명 일일 증분 수집.

## 🔗 온톨로지 연합 URN
- 문화예술인 URN: `urn:culture:artist:{category}:{artist_id}`
- 글로벌 인물 URN: `urn:people:person:{nationality}:{entity_id}`
- 협업/인맥 URN: `urn:people:network:{relation_type}:{person_a}:{person_b}`
