# 렛츠 패밀리 디자인시스템 적용

신규 화면은 [`Lets Design System`](https://github.com/pyw31337/lets/blob/main/docs/LETS_DESIGN_SYSTEM.md) v1.1.0을 기준으로 한다. 공통 CSS/JS는 `lets/css/lets-design-system.css`, `lets/js/lets-design-system.js`, 토큰은 `lets/tokens/lets-design-tokens.json`을 사용한다. 기존 완성 화면은 회귀 위험이 있는 경우 예외 문서에 사유와 폐기일을 남긴다.
